Ratan OS Lite AI Edition v1.2.0 — offline Qwen3-4B for authorized security learning.

The current Ratan OS Lite AI Edition combines compact Tool Collections with an embedded, CPU-only Qwen3-4B assistant. The assistant runs locally after boot: it needs no Internet connection, cloud account or API key. This page provides permanent download parts, verification instructions and the operating boundary before users boot the image.

After downloading, run grep 'part-' SHA256SUMS | sha256sum -c -, then cat ratan-os-lite-ai-amd64.iso.part-* > ratan-os-lite-ai-amd64.iso, followed by sha256sum -c SHA256SUMS. The expected final ISO SHA-256 is 7aa2c6a95a71bf99df2c3d774a817419295664403eb56b15dceb7b1f3531a90d.
