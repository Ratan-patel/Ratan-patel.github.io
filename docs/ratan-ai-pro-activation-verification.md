# Ratan AI Pro Activation Verification

The live Ratan Research Center payment page now contains a dedicated RATAN AI Pro section for **5 USDT per 30 days**. It states the USDT ERC-20-only network requirement, the manual transaction-hash confirmation process, and the absence of automated debits or recurring blockchain transfers.

The user-facing flow requests only the transaction hash, payment time, and response email. It explicitly warns users never to provide seed phrases, private keys, wallet credentials, OTPs, passwords, or remote-device access. The page also makes clear that account-level gating and automated renewal are not enabled in this release.
