[01] CURRICULUM_STRUCTURE

The credit distribution and foundational pillars of the 123-126 unit graduate program.

PROGRAM SCOPE
75-78 Core Units + 48 Elective Units
FOUNDATIONAL PILLAR 24 UNITS

Security Core

Covers essential threat models, cryptographic algorithms, network configurations, and host-level defense strategies. Consists of 14-741 (Intro to Information Security) plus one specialized offensive or defensive elective.

SYSTEMS & ARCHITECTURE 24 UNITS

Systems & Networking Core

Requires selecting core modules in advanced operating systems, distributed architectures, storage platforms, and low-level network packets to develop an absolute, end-to-end understanding of how data executes and traverses.

GOVERNANCE & STEWARDSHIP 12 UNITS

Cyber Risk Modeling

Instructs professionals in quantifiably modeling threats, security policies, information security management regulations, and financial/business impact assessments to articulate complex tech findings to executives.

[02] CORE_COURSE_DEEP_DIVE_&_OFFENSIVE_ALIGNMENT

Analyzing five pivotal curriculum blocks and detailing their high-value alignment to penetration testing and ethical hacking.

[REQUIRED_BASE]

14-741: Introduction to Information Security

12 Units | Fall & Spring

CREDIT TYPE
Security Core
CERTIFICATION LINK
NSA CAE-C Core

// Course Overview

Covers foundational mathematical and cryptographic baselines. Focuses on symmetric/asymmetric encryptions, access control policies, security designs, and basic system exploit pathways.

Ethical Hacking / Penetration Testing Alignment

Fundamental for cryptanalysis and threat modeling. Provides the structural comprehension needed to evaluate encryption bypasses, map corporate attack vectors, and identify vulnerabilities in standard access control designs.

[REVERSE_ENGINEERING]

14-735: Secure Coding

12 Units | Fall

CREDIT TYPE
Security Core (Elective)
RELEVANT SURFACES
C/C++, Rust, Assembly

// Course Overview

Investigates secure software development structures, emphasizing memory safety errors (buffer overflows, heap exploitation, integer wraps, format strings) and mitigation controls (ASLR, DEP, Stack Canaries).

Ethical Hacking / Penetration Testing Alignment

Directly maps to binary exploitation and reverse engineering. Teaches the micro-architectural physics of how software breaks, enabling pen-testers to craft manual exploit payloads and safely assess systems-level applications.

[WEB_APP_OFFENSIVE]

14-828: Browser Security

12 Units | Spring

CREDIT TYPE
Security Core (Elective)
ATTACK SURFACES
SOP, CORS, CSP, DOM, XSS

// Course Overview

Examines client-side browser logic, sandbox environments, and web application isolation policies. Analyzes vulnerabilities in Same-Origin Policy (SOP), session tokens, and modern client-side scripting frameworks.

Ethical Hacking / Penetration Testing Alignment

Essential for web application security assessments. Understanding browser sandboxing mechanisms allows ethical hackers to bypass endpoint defensive shields, bypass CORS controls, and build multi-stage client-side XSS/CSRF exploits.

[NETWORK_RECON]

14-760: Advanced Real-World Data Networks

12 Units | Spring

CREDIT TYPE
Networking Core
INFRASTRUCTURE
SDN, Routers, SDN, NFV

// Course Overview

A hands-on, highly practical exploration of modern enterprise-level network deployments. Covers software-defined networking, routing protocols, advanced configurations, and data center network designs.

Ethical Hacking / Penetration Testing Alignment

Critical for packet analysis and pivoting. Ethical hackers leverage this infrastructure knowledge to perform deep network sniffing, ARP spoofing, VLAN hopping, and protocol manipulation inside virtualized corporate network fabrics.

[HARDWARE_&_IOT]

14-642: Intro to Embedded Systems

12 Units | Fall

CREDIT TYPE
Systems Core
HARDWARE LAYER
Firmware, JTAG, Microcontrollers

// Course Overview

Investigates embedded kernels, micro-controllers, memory-constrained architectures, physical bus interfaces, and firmware assembly designs. Focuses heavily on direct hardware-software co-execution.

Ethical Hacking / Penetration Testing Alignment

Directly maps to IoT and Hardware exploitation. Teaches ethical hackers how to connect to physical debug ports (JTAG/UART), dump running firmware, reverse engineer compiled binary code, and exploit embedded interfaces.

[03] MODULAR_TRAINING_IMPLEMENTATION_PLAN

A strategic blueprint to convert CMU’s academic core into a practical, phased corporate ethical hacking syllabus.

01

Phase 1: Foundational Systems

Corresponding: Systems & Networking

Before learning to break systems, students must master low-level operating systems and packet analysis. Training covers assembly basics, TCP/IP headers, routing configuration, and passive/active reconnaissance.

02

Phase 2: Offensive Specialization

Corresponding: Security Core

Hands-on instruction in penetration testing techniques. Includes binary exploitation (buffer overflows), web vulnerability hunting (XSS, SQLi), and defensive secure coding patterns to remediate active flaws.

03

Phase 3: Risk & Policy

Corresponding: Risk Modeling Core

Bridges technical hacking with executive decisions. Students learn to draft industry-standard penetration test reports, construct quantitative cyber risk models, and map technical findings directly to business impact.
