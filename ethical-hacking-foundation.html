Curriculum

Every week combines a short lesson, a safe lab exercise and a written deliverable.

WEEK 01 // CORE

Security mindset and authorization

Learn why scope and evidence matter before any tool is opened.

  • Rules of engagement and asset inventory
  • Threats, risks and attack surface
  • Linux terminal and file discipline
  • Lab: write a safe test plan
WEEK 01 // NETWORKS

Networking and HTTP

Understand the requests that make modern applications work.

  • IP, DNS, TCP and TLS concepts
  • HTTP methods, headers and cookies
  • Browser security controls
  • Lab: map a local application flow
WEEK 02 // RECON

Reconnaissance and validation

Turn discovery into a prioritized test list.

  • Passive versus active discovery
  • Service and technology identification
  • False positives and validation
  • Lab: build an authorized asset map
WEEK 02 // WEB

OWASP web security basics

Recognize common vulnerability classes without unsafe exploitation.

  • Input validation and output encoding
  • Authentication and session concepts
  • Access control and data exposure
  • Lab: document a controlled finding
WEEK 03 // ACCESS

Identity and authorization testing

Test role boundaries and ownership assumptions.

  • Horizontal and vertical access checks
  • Object ownership and least privilege
  • Safe evidence collection
  • Lab: create a reproducible report
WEEK 03 // INPUT

Input and configuration review

Find weak validation and security misconfiguration patterns.

  • Injection concepts and safe proofs
  • Security headers and exposed files
  • Error handling and logging questions
  • Lab: remediation checklist
WEEK 04 // REPORTING

Writing findings developers can fix

Communicate impact without exaggeration.

  • Severity and likelihood reasoning
  • Minimal reproduction steps
  • Root cause and remediation
  • Lab: executive summary
WEEK 04 // CAPSTONE

Authorized mini assessment

Complete a small lab assessment from scope to sign-off.

  • Choose three test hypotheses
  • Capture evidence and limitations
  • Submit a prioritized report
  • Instructor review and certificate

Student workflow

01 // Learn

Study the brief and explain the security concept in your own words.

02 // Practice

Use the supplied lab, stay in scope and record what you observed.

03 // Report

Submit evidence, impact and remediation for instructor feedback.

04 // Complete

Pass the capstone review to receive the completion certificate.
