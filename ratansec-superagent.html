Safety jo enforce hoti hai, suggest nahi

Aapke paas authorization hai — system uska record rakhta hai aur uske bahar kuch nahi hone deta.

user / AI │ tool call ▼ [1] catalog gate → sirf defined tool + defined flags (argv-only) [2] scope check → target authorised? (default DENY) [3] hard blocks → 169.254.x.x · metadata · multicast · 0.0.0.0 [4] approval gate → intrusive tools + shell = human tap (phone) [5] executor → timeout · output cap · cancel · no shell [6] audit+evidence → hash-chained JSONL (tamper-evident)

Engagement records (RoE)

Client, scope hosts, permitted sections, validity window, signer + SOW reference. Record ke bina agent ke paas koi command nahi — aur section record me nahi to us section ka tool bhi nahi.

Human-in-the-loop

Brute-force, exploitation, post-exploitation, hash cracking, wireless aur raw shell — sab par ek tap chahiye. Approve karne se pehle exact command dikhta hai. 20 min me expire.

Tamper-evident evidence

Har event prev_hash → hash chain me. Verify endpoint batata hai kaunsa record toota. Ek click me evidence bundle (zip) — audit + ledger + manifest.

Quick start

Python 3.10+, 3 dependencies. Tools Kali/Debian/Ubuntu ya Termux par.

# 1) backend + UI
cd ratansec-os
python3 -m venv .venv && source .venv/bin/activate
pip install -r superagent/requirements.txt

# 2) config (apni private API key)
cp superagent/.env.example .env
#   APP_PASSWORD=…  SUPERAGENT_API_TOKEN=…
#   SUPERAGENT_API_KEY=sk-…  SUPERAGENT_ALLOW_SHELL=1

# 3) tools (jitne chahiye)
bash scripts/install-agent-tools.sh core

# 4) chalao
bash scripts/superagent.sh          # http://localhost:8000

Authorization — records aapke paas, enforcement system ke paas

Har engagement ke liye ek record banao. Repo me ready-to-sign letter template aur legal checklist bhi hai.

1. Authorization letter

Client letterhead par: scope (Annexure A), window + rate limits (Annexure B), constraints, emergency contacts, liability. Template ↗

2. Record banao

Records tab me wahi details daalo — client, hosts, sections, dates, signer + SOW/email reference. Record hash-chain me jud jaata hai.

3. Kaam karo — audited

Har command, approval, report aur revoke evidence chain me. Engagement ke baad record revoke karo (permanent entry banti hai).

4. Report + bundle

AI se report draft, phir evidence bundle export (audit + RoE ledger + chain verification manifest) client ko de do.
