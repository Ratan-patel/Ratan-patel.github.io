Plan → approve → execute → evidence → report

Autonomy bounded hai; accountability nahi.

1. RoE record

Client, exact scope, validity window, signer aur authorization reference. Default deny — record ke bina live mission nahi.

2. Exact-plan approval

Probe list + target + plan SHA-256 approval card par. Approve ke baad hi traffic; revoke/expire par execution refuse.

3. Bounded probes

No redirects, no credentials, no payloads, timeouts, DNS pinning, well-known text caps. Emergency stop available.

4. Evidence + report

Per-step JSON artifacts with SHA-256, hash-chained audit, Markdown report with limitations and remediation.

5. Private AI

OpenAI-compatible provider ya local Ollama/LM Studio/vLLM. Key sirf server environment mein; browser ko key return nahi hoti.

6. Dashboard + mobile + CLI

Responsive PWA console, mission CLI, OpenAPI docs. Offline demo bina key aur bina target traffic ke chalta hai.

Safety jo enforce hoti hai

Quick start

Python 3.10+. Offline demo ke liye key nahi chahiye.

# offline demo (fixture only)
cd ratansec-os
python3 -m venv .venv && source .venv/bin/activate
pip install -r superagent/requirements.txt
bash scripts/superagent.sh --demo

# live private setup
cp superagent/.env.example .env
chmod 600 .env
# edit locally: APP_PASSWORD / SUPERAGENT_API_TOKEN / provider key
bash scripts/superagent.sh

Local model: SUPERAGENT_PROVIDER=ollama, SUPERAGENT_BASE_URL=http://127.0.0.1:11434/v1. Remote access ke liye HTTPS reverse proxy use karo.
