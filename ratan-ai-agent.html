RATAN AI AGENT // ANDROID RELEASE & TRUST CENTER

Your own API key, or the hosted agent — your choice, on your phone.

RATAN AI AGENT 2.1 is the Android build of the RATAN AI assistant. It ships pointed at the hosted assistant, and it can just as easily run on your own provider: an OpenAI-compatible endpoint, Anthropic, a local Ollama server, or any private JSON API you can describe. Keys live in the Android Keystore, and the whole AI red-team toolkit travels inside the APK so it works with no network at all. The app is built from source in this repository by GitHub Actions — not uploaded as an opaque binary.

What changed in 2.1 — the API is now optional

2.0 shipped pointed at the hosted assistant. 2.1 keeps that as the default and adds a second path: run the app on your own credentials, from inside the app.

Presets for OpenAI-compatible endpoints, Anthropic and Ollama, plus a Private / Custom mode where you supply the path, headers, body template and response path — so any JSON API works, including a client's gateway or your own lab service.

02 // CREDENTIALS

Keys in the Android Keystore

The key is encrypted with an AES-256-GCM key held by the device keystore. It is write-only from the page's point of view: the dashboard can save a key and can only ever read back a masked tail.

AES-256-GCMNever surfaced to JSRedacted in errors
03 // SCOPE OF USE

The page cannot choose the destination

The request URL is assembled in native code from your stored profile, so a compromised page cannot aim your credential at a server of its own choosing. Credentials are dropped on cross-host redirects, and one completion runs at a time.

Which API can I plug in?

Anything that speaks one of these four shapes. Leave the toggle off and the hosted RATAN AI agent behaves exactly as before — nothing else in the app changes.

PresetCoversNotes
OpenAI-compatible OpenAI, Azure OpenAI, Groq, Together, OpenRouter, vLLM, LM Studio, llama.cpp server, self-hosted gateways Blank base URL means https://api.openai.com; the app appends /v1/chat/completions, or accepts a full URL you paste.
Anthropic Claude models Adds x-api-key and anthropic-version, moves the system prompt out of band, always sends max_tokens.
Ollama A model server on your laptop or a lab box No key required. From the phone use the machine's LAN address, not localhost, and grant local-network access.
Private / Custom Any JSON API: an internal gateway, a brokerage of models, a client's staging bot You set the path, extra headers, the request body template and the response path (for example choices[0].message.content).

Body-template placeholders: {{MODEL}} {{PROMPT}} {{MESSAGES}} {{SYSTEM}} {{TEMPERATURE}} {{MAX_TOKENS}}, plus {{KEY}} inside headers only. A built-in Test connection button reports the provider's own error text with a plain-language hint (rejected key, unknown model, wrong path, rate limit, unreachable host, missing LAN permission).

What else is in the app

HOSTED AGENT

RATAN AI, one tap away

The hosted assistant opens inside the app. If the network drops, the app falls back to its local dashboard instead of showing an error page.

OFFLINE TOOLKIT

67 probes with no network

The bundled AIRT engine fires prompt-injection, jailbreak, exfiltration, tool-abuse and boundary probes across 11 categories with 9 evasion mutations — in aeroplane mode, against a lab bot on your own Wi-Fi.

ANDROID 17 READY

Local-network permission handled

Android 17 requires an explicit grant before an app may touch the LAN. The shell declares ACCESS_LOCAL_NETWORK, asks at the right moment, and tells you plainly when a LAN target is refused because the grant is missing.

NATIVE BRIDGE

No CORS wall

Requests are made natively, so a plain http://192.168.x.x staging bot or local model server is reachable from the phone. Per-hop redirect policy, response caps, gzip, header-injection guards.

HARDENED SHELL

Trusted pages only

Only the bundled pages and the origin you configured render in-app; every other link leaves the app. No mixed content, no remote file:// reads, Safe Browsing on, third-party cookies off.

REPORTS & DIAGNOSTICS

Evidence, not vibes

Exports land in Downloads/ as JSON, standalone HTML and SARIF 2.1.0. A one-tap self-test reports build, device, WebView engine, permissions, signature and endpoint reachability for support.

Troubleshooting

"App not installed" while updating

An older RATAN AI AGENT build (1.0 or 1.1) is still installed. Uninstall it, then install 2.1 — everything from 2.0 onwards shares one signing key and upgrades in place.

Chat says "mode is set to the hosted agent"

Turn on Use my own API for chat in section 06. The hosted assistant stays available in section 01 regardless.

HTTP 401 or 403 from my provider

The credential was rejected. Paste it again with Save key and check that the key is allowed to call the model you named.

HTTP 404, or "no completion text was found"

Endpoint or response shape mismatch. OpenAI-compatible servers usually want /v1/chat/completions; for a private API set the path and the response path yourself (for example data.output.text).

HTTP 429

Rate limit or exhausted quota on that key or model. Wait, switch keys, or pick a smaller model.

Ollama on my laptop is unreachable

localhost on the phone means the phone. Use the laptop's LAN address and grant local-network access from the dashboard (section 04).

LAN scan says "permission required"

Android 17 blocks LAN access until the local-network permission is granted. Tap Grant LAN access on the dashboard and accept the dialog.

Storage / backup question

Scan reports go to Downloads/ and API keys to the Keystore. Nothing is uploaded anywhere by the app: no analytics, no crash reporting, no third-party SDKs.

Operating boundary

Authorised testing only. The bundled toolkit sends real adversarial prompts, and the native bridge can reach anything the phone can route to — including a LAN target or a provider endpoint. Use the app, its API configuration and its toolkit exclusively against systems you own or have written permission to test, and use API keys and provider accounts you are entitled to use. Prompt injection can make a target disclose data or run tool calls: prefer a staging endpoint and a scratch account, and assume anything the model can reach may be exposed.

Also in the toolchain

The same 67-probe corpus runs as a zero-dependency Python CLI and web console on a laptop — handy when the target is better reached from the desk than from the phone.
