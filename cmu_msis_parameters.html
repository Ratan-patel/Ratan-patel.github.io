CMU MSIS DEGREE PARAMETERS

Syllabus Structure and Curricular Requirements

The Master of Science in Information Security (MSIS) at Carnegie Mellon University is structured across seven fundamental parameters. Below is a comprehensive, page-by-page detailed exploration of each parameter, detailing coursework requirements, academic philosophies, and mappings to ethical hacking.

01

Parameter 01: Systems Core (12 Units)

The Systems Core parameter is the engine room of the CMU MSIS degree. At a graduate level, cybersecurity cannot be treated as a pure software layer; it must be understood at the compiler, operating system, and hardware architecture levels. This parameter ensures that students understand the exact physics of process execution, distributed databases, memory spaces, and system kernels. Without this foundation, an engineer is merely using security tools without understanding how they interact with unmanaged hardware or virtualized resources.

In this parameter, students choose from a pre-approved list of rigorous systems courses. 15-605 (Operating System Design and Implementation) requires students to build a fully functional operating system kernel from scratch in C, managing context switching, virtual memory mapping, thread schedulers, and device drivers. 14-736 (Distributed Systems) examines how modern web-scale systems maintain integrity, consistency, and consensus (using algorithms like Paxos or Raft) across untrusted, high-latency physical servers. Other courses include 15-746 (Storage Systems) which explores physical flash wear-leveling, raid arrays, and file system security boundaries.

Ethical Hacking Alignment: The Systems Core is the birthplace of advanced exploit development. An offensive cybersecurity specialist cannot exploit memory corruption (such as heap overflows, double frees, or use-after-free conditions) without an absolute, low-level understanding of process memory layouts, register management (EIP/RIP pointers), and compiler-level mitigations. This parameter transitions students from surface-level script users into elite systems security engineers who can perform bare-metal analysis and identify zero-day vulnerabilities in enterprise operating systems.

02

Parameter 02: Networking Core (12 Units)

The Networking Core parameter represents the nervous system of modern cybersecurity. It governs the structural transport, encapsulation, and routing rules that connect distributed computing assets. In corporate and cloud environments, security is defined by boundaries, access control policies, and data-in-transit encryption. To secure or audit these networks, a professional must master the stateful transport of packets and the configurations of virtualized and software-defined network fabrics.

This parameter requires the completion of an advanced network architecture course. In 14-740 (Fundamentals of Telecommunications and Computer Networks) or 14-760 (Advanced Real-World Data Networks), students deep-dive into the OSI and TCP/IP stacks, learning exactly how packet headers are constructed, parsed, and routed. Students explore Layer 2 switching protocols (VLANs, Spanning Tree), Layer 3 interior and exterior routing (OSPF, BGP), Layer 4 stateful flow control (TCP windowing, congestion control), and the cryptographic handshakes of SSL/TLS and IPSec VPN tunnels.

Ethical Hacking Alignment: Critical for network-wide reconnaissance, packet manipulation, and lateral movement. An offensive expert utilizes this knowledge to perform stateless packet crafting, execute active Man-in-the-Middle (MitM) attacks (such as ARP poisoning, DNS hijacking, or DHCP starvation), and analyze weaknesses in global routing infrastructures (BGP hijacking). Furthermore, understanding how Software-Defined Networking (SDN) and Network Function Virtualization (NFV) isolate cloud environments is critical for bypassing modern corporate defenses and executing safe network penetration testing.

03

Parameter 03: Security Core (24 Units)

The Security Core parameter is the theoretical and applied heart of the MSIS degree. This block requires double the unit weight of other parameters, representing a deep commitment to both academic cryptographic theories and hands-on offensive/defensive methodologies. It is specifically designed to align with national standards and is a major contributor to CMU's designation as a National Center of Academic Excellence in Cyber Operations (CAE-CO).

This parameter consists of two parts: a mandatory gateway course, 14-741 (Introduction to Information Security), plus a pre-approved specialized security elective. 14-741 establishes the cryptographic foundations (symmetric block ciphers, public-key algorithms, secure hashing, digital signatures), access control theory (DAC, MAC, RBAC, ABAC), and classic formal security models (Bell-LaPadula confidentiality, Biba integrity, Clark-Wilson transactions). The elective allows students to specialize in high-value offensive or defensive tracks, selecting from courses like 14-735 (Secure Coding), 14-828 (Browser Security), 18-731 (Network Security), or 18-732 (Secure Software Systems).

Ethical Hacking Alignment: This parameter represents the core technical skillset of the penetration tester. 14-741 provides the mathematical knowledge necessary to break cryptographic implementations, while courses like Secure Coding and Browser Security teach the exact methods to find and exploit software vulnerabilities. Students master the mechanics of memory execution, client-side browser sandboxing, and web API defenses. It represents a structured, academic approach to 'learning how to think like an attacker' within a strict, legal, and ethical framework.

04

Parameter 04: Business & Management Core (12 Units)

The Business & Management Core parameter represents the executive interface of the cybersecurity program. Technical excellence is useless if it is decoupled from corporate strategy, financial realities, and regulatory compliance. This parameter ensures that graduate engineers can translate highly technical vulnerabilities, threat vectors, and data breaches into quantifiable, business-centric risk matrices that board members and executives can act upon.

Students satisfy this requirement by taking 14-817 (Cyber Risk Modeling) or a sequence of management courses including 14-782 (Information Security Risk Management I) and 14-788 (Information Security Policy and Management). The curriculum utilizes quantitative risk analysis frameworks (such as FAIR - Factor Analysis of Information Risk) to model threat frequencies and loss magnitudes mathematically. It also covers international compliance landscapes, security frameworks, and auditing standards (ISO 27001, NIST CSF, SOC 2 Type II, PCI-DSS, GDPR) alongside incident response planning and policy formulation.

Ethical Hacking Alignment: In the field of ethical hacking, this parameter is critical for professional penetration testing delivery. Corporate clients do not pay penetration testers simply to show off exploit chains; they pay for a clear, actionable assessment of corporate risk. This parameter teaches ethical hackers how to map technical vulnerabilities (such as cross-site scripting or database leaks) directly to business impact, compute the potential financial loss, and formulate prioritized remediation roadmaps. It ensures that security trainers and consultants can articulate security value directly to executive leadership.

05

Parameter 05: MSIS Degree-Specific Core (12 Units)

The MSIS Degree-Specific Core parameter provides targeted specialization to ensure depth of expertise. In addition to the broad foundational cores, this block requires students to take at least one pre-approved, highly technical graduate-level security course from the MSIS Degree-Specific list. This parameter allows students to tailor their degree to align with their specific career objectives, whether that is malware analysis, mobile and IoT security, or privacy-enhancing technologies.

Courses in this parameter are highly specialized and practitioner-led. Examples include 14-822 (Host-Based Vulnerability Analysis), where students analyze low-level software execution and learn reverse-engineering; 14-829 (Mobile Security), which focuses on cellular network architectures, mobile OS sandboxing, and application static analysis; and 14-735 (Foundations of Privacy), exploring data anonymization, differential privacy, and legal frameworks.

Ethical Hacking Alignment: For ethical hackers, this parameter is where they develop specialized competitive advantages. In modern cybersecurity, being a generalist is rarely enough. An ethical hacker specializing in IoT must master physical embedded circuits, whereas a cloud auditor must master container security and IAM structures. This parameter provides the dedicated, deep-dive academic environment to master these advanced sub-fields, enabling researchers and trainers to build highly specialized testing methodologies.

06

Parameter 06: Academic & Professional Development (3 Units)

The Academic & Professional Development parameter (14-601) represents the leadership and professional core of the graduate experience. Cybersecurity is not merely a technical or business challenge; it is a human challenge that requires communication, ethics, strategy, and leadership. This parameter ensures that students transition from individual engineers into strategic leaders, public speakers, and ethical stewards of corporate security programs.

Delivered by the INI's specialized academic affairs team, this parameter guides students through intensive professional workshops, resume critiques, mock interviews, leadership panels, and technical presentation exercises. It also includes rigorous training in ethical guidelines, legal responsibilities, and professional standards expected of high-level information security officers.

Ethical Hacking Alignment: In ethical hacking, professional development and ethics are paramount. Operating as an ethical hacker means possessing tools and techniques that could cause massive financial or reputation damage if misused. This parameter instills the mandatory ethical boundaries, rules of engagement (RoE), and authorization protocols that separate legitimate security professionals from malicious actors. It also trains security consultants to deliver clear, polished verbal presentations to stakeholders, converting raw exploit findings into strategic solutions.

07

Parameter 07: Program Electives (48 Units)

The Program Electives parameter represents the flexible, interdisciplinary frontier of the CMU MSIS degree, accounting for roughly one-third of the total required units (48 units). Cyber security does not operate in a vacuum—it overlaps with artificial intelligence, hardware design, public policy, robotics, and business administration. This parameter allows students to select advanced graduate-level courses from CMU's top-tier departments to build a highly unique, customized educational profile.

Students can select electives from the Information Networking Institute (INI), Department of Electrical and Computer Engineering (ECE), School of Computer Science (SCS), Engineering and Public Policy (EPP), Heinz College of Information Systems and Public Policy, or the Tepper School of Business. This allows students to study cutting-edge topics such as Machine Learning with Adversaries in Mind, Hardware-Level Cryptography, Cyber Warfare and National Security Policy, or Advanced Cryptography.

Ethical Hacking Alignment: The Electives parameter is a sandbox for cross-disciplinary innovation. Modern attack vectors increasingly target emerging technologies like Machine Learning systems (e.g., adversarial prompt injection, model poisoning). By taking advanced SCS or ECE electives, an ethical hacker can develop proactive penetration testing methods for next-generation platforms, staying ahead of malicious actors and maintaining their status as cutting-edge security leaders and trainers.
