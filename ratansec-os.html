Features — asli, chalne wale

// AI

AI Copilot (tool-calling)

Hinglish/English instruction do — AI khud run_scan, run_command, generate_report jaise tools call karta hai, output analyze karta hai aur next steps suggest karta hai. Koi bhi OpenRouter model (GPT-4o, Claude, Gemini, Llama, DeepSeek, free models bhi).

// SCAN

6 Professional Profiles

quick recon · web (WhatWeb + Nikto + gobuster) · network top-1000 ports + scripts · vuln (nmap vuln + Nuclei CVE templates) · webapp (sqlmap + ffuf) · full sab kuch.

// SAFETY

Human-in-the-Loop

sqlmap/hydra jaise intrusive tools aur scope ke bahar wale targets par dashboard me Approve / Deny card aata hai. Approve karne par wahi scan chalta hai aur AI result aage analyze kar deta hai.

// SCOPE

Scope Allowlist

ALLOWED_TARGETS me apne domains/wildcards/CIDR daalo — bahar ka kuch bhi scan nahi hoga. Cloud metadata IPs (169.254.x.x) hard-blocked — SSRF-style abuse impossible.

// EXEC

Injection-Proof Execution

Har command argv list ke roop me chalti hai (shell=False) — ; rm -rf / jaisa injection impossible. Per-step timeout, output caps, cancel support, background runs.

// REPORT

AI Reports + Audit Log

Ek click me Markdown report jisme AI ka analysis hota hai (findings, risk, next steps). Saath me audit.jsonl — kaun, kab, kya chalaya — evidence ke liye.

// NOTE

QCOW2 vs RAW IMG

QCOW2 = compressed + import-friendly (Oracle Custom Image, Proxmox qm importdisk, GCP). RAW IMG = unzip karne par ~3.5 GB ka plain disk — un tools/providers ke liye jo raw maangte hain.

// NOTE

ISO OS nahi hai

ratansec-seed.iso sirf 40 KB ka config disc hai (cloud-init user-data). Poora OS VM images (qcow2/vmdk/vdi/img) ke andar hai. Seed ISO us VM ke liye hai jisme tum stock Ubuntu 24.04 cloud image use kar rahe ho.

// RASTA 1

VM image import (recommended)

QCOW2 download karo → cloud/VM me import → boot → 4–6 min baad dashboard live. Oracle Cloud free tier ARM (Ampere) par ARM64 image, x86 VM par amd64.

# Oracle Cloud (steps)
Storage → Buckets → qcow2 upload
Compute → Custom Images → Import image (OS: Ubuntu 24.04)
Custom image → Create Instance → SSH key
Security List → Ingress: TCP 8000 · 0.0.0.0/0

# Proxmox
qm importdisk 900 ratansec-os-1.0.0-amd64.qcow2 local-lvm
qm set 900 --scsi0 local-lvm:vm-900-disk-0 --ide2 local-lvm:cloudinit
// RASTA 2

Seed ISO (kuch bhi platform)

Koi bhi Ubuntu 24.04 cloud VM chalao → ratansec-seed.iso ko 2nd CD-ROM me attach karo → boot. Cloud-init baaki sab kar dega.

# Multipass (laptop par fastest)
multipass launch 24.04 --name ratansec --memory 4G --disk 20G \
  --cloud-init ratansec-os/deploy/cloud-init/user-data
multipass exec ratansec -- sudo cat /root/ratansec-credentials.txt

FAQ — jo sab poochhte hain

Kya yeh 25 MB me aa sakta hai?

Nahi — aur koi bhi OS + hacking tools 25 MB me nahi aate (Kali ISO khud ~4.5 GB hai, Metasploit ~400 MB, ek chhota AI model 300 MB+). RatanSec OS ka core code sirf ~500 KB hai, par tools aur VM image bade rehte hain. Isi liye design aisa hai: AI layer halka (tumhari API key se chalti hai) aur tools cloud VM me (on-demand).

AI key kiski? Paisa kitna lagega?

AI sim ki apni OpenRouter key (free account + free models possible). Software aur VM images free hain. Paid models par ek scan+analysis ≈ ₹0.2–1; roz 20 scans ≈ ₹150–600/mahina. Server: Oracle Cloud Always Free (4 ARM CPU/24 GB RAM) par ₹0, ya $5–6/mo VPS.

Kaunse tools andar hain?

nmap · nikto · whatweb · gobuster · ffuf · nuclei · sqlmap · hydra · whois · dig · curl · netcat — aur registry extend karna ek JSON block jitna aasan hai. Missing tools ke install commands dashboard ke Tools tab me dikhte hain.

Mobile par chal sakta hai?

Haan — do tarike: (1) Termux me ./setup.sh (nmap/curl/whois chalte hain), (2) cloud par deploy karke phone ke browser se dashboard use karo (recommended).

Kya yeh Kali ko replace karta hai?

Yeh Kali/Pentest distro ko replace nahi karta — yeh unke upar AI layer + orchestration deta hai. Tumhare tools wahi rahte hain, bas ek copilot unhe chala kar samjhata hai, aur poora kaam dashboard + audit log me organised rehta hai.

Source code kahan hai? Kya main modify kar sakta hoon?

Poora source GitHub par hai — ratansec-os/ folder (FastAPI backend, agent loop, tool registry, dashboard, CLI, CI builders). Customise karo: naya tool add karo, apni profiles banao, apna model/endpoint lagao.
