AIRT — AI Red-Teaming Scanner

A lightweight Python CLI and web console that fires automated prompt-injection, jailbreak, data-exfiltration, tool-abuse and boundary tests at any AI endpoint — an OpenAI-compatible API, Claude, a local Ollama model, or your own LangChain / FastAPI bot over plain HTTP.

Authorised testing only. AIRT sends real attacks at a live model and can cause a target to disclose data or execute tool calls. Only run it against systems you own or are contracted to test, on a staging endpoint with a scratch account. The CLI requires explicit confirmation; the web console blocks non-local targets unless started with --allow-remote.

What it does

Attack corpus

Instruction override, ChatML token smuggling, DAN/dev-mode/AIM personas, many-shot priming, system-prompt extraction, markdown-image exfiltration beacons, credential solicitation, SSRF-to-metadata, insecure code generation, hallucinated citations, bias probes and indirect (RAG/email/PDF) injection.

Explainable scoring

Every verdict ships with evidence: canary hits, marker echoes, secret/PII regexes, refusal language, compliance heuristics and system-prompt similarity. Refusals are detected in English, Hinglish, Spanish and French.

Evasion testing

The same attack re-sent as base64, ROT13, zero-width, homoglyph, leetspeak, fullwidth, roleplay-wrapped or bilingual payloads — then an effectiveness table that shows whether your defence is a policy or just a keyword filter.

Android APK

Same corpus and scoring engine, packaged as an installable app (Android 7.0+, ~40 KB, debug-signed sideload). It calls endpoints natively, so CORS never blocks it and plain-http:// lab bots work; reports land in Downloads/ as JSON/HTML/SARIF. Built automatically by GitHub Actions. Download APK →

Web console

python3 -m airt serve gives a single-page UI over the same engine: pick target, categories and mutations, watch live progress, download JSON/HTML/SARIF generated locally. No CDN, no third-party JS, no data leaves the box.

Run it

git clone https://github.com/Ratan-patel/Ratan-patel.github.io.git
cd Ratan-patel.github.io/tools/ai-redteam-scanner

# offline demo — no target, no API key, no network
python3 -m airt demo --mutate-all

# your own bot over HTTP
python3 -m airt scan --target-type http --target-url http://localhost:8000/chat \
    --body '{"message":"{prompt}"}' --response-path reply \
    --inject-canary --html report.html --sarif report.sarif --yes

# web console
python3 -m airt serve --port 8765

Design honesty

Scoring is heuristic and deterministic (no LLM judge dependency), so a creative or partial compliance can land as inconclusive — the report shows the raw prompt/response pair and the evidence, so a human can adjudicate in seconds. Probes request harmful content but contain no working exploit code, credentials or weapon instructions. Multi-turn crescendo attacks are on the roadmap; today's deferred-rule probes only verify that a planted rule is echoed.
